# Power BI: BullScope

## Open the ready-made project

`BullScope/BullScope.pbip` is a **Power BI Project** (text-based PBIP format) that contains:

- the data model: 8 tables loaded with Power Query from `data/processed/`, a `Date` table (2019–2027, marked as date
  table), a `Top N` what-if table and 8 relationships (star schema);
- **77 DAX measures** in a `_Measures` table, in 7 display folders (Stocks, Buy Sell Flow, Indices, FII DII,
  Mutual Funds, Fund Holdings, Options);
- 4 starter report pages: **Market overview**, **Buy sell flow**, **Mutual funds**, **Holdings & options**.

Steps:
1. Install **Power BI Desktop** (free, Microsoft Store). If asked, enable *File → Options → Preview features →
   Power BI Project (.pbip) save option* and *Store semantic model using TMDL format*, then restart.
2. Double-click `BullScope/BullScope.pbip`.
3. If the repo is not at `C:\Users\Rahul\projects\GitHub-Projects\bullscope`, go to
   *Transform data → Edit parameters* and set `DataFolder` to your `data\processed\` folder (ending in `\`).
4. Click **Refresh**. Apply the theme (*View → Themes → Browse* → `theme/bullscope_theme.json`),
   tidy the layout, then **File → Save as** `BullScope.pbix` and take screenshots into `screenshots/`.

The project is generated by `python scripts/build_bi_files.py` from `measures.dax` and the table list in that
script, so those stay the single source of truth.

## Build it by hand

| File | What it is |
|---|---|
| `power_query.m` | Power Query (M) for all 8 tables, types set with the en-US locale |
| `measures.dax` | 77 DAX measures grouped by display folder |
| `theme/bullscope_theme.json` | Report theme (colour-blind-safe palette) |

1. **Load data**: *Transform data → Manage parameters → New* `DataFolder` (Text) = path to `data\processed\`.
   For each block in `power_query.m`: *New Source → Blank query → Advanced Editor*, paste, rename. *Close & Apply*.
2. **Date table**: *Modeling → New table* with the `DATE_DAX` expression from `scripts/build_bi_files.py`; mark as
   date table; sort `Month` by `Month Start`.
3. **Relationships** (one → many, single direction):
   `Date[Date]` → Stock Prices, Index Prices, Fund NAV, FII DII ·
   `Stocks[sym]` → Stock Prices[symbol], Fund Holdings[symbol] ·
   `Funds[scheme_code]` → Fund NAV, Fund Holdings.
4. **Measures**: create a `_Measures` table and paste the measures from `measures.dax`.

## DAX worth a look

- `Last Close` / `First Close` use `LASTNONBLANK` / `FIRSTNONBLANK` over the date table, so returns follow any slicer.
- `Net Flow Rank` + `Show Top N Bought` drive a dynamic Top-N with the `Top N` what-if slicer.
- `Max Pain` builds a virtual table of strikes with `ADDCOLUMNS` and returns the strike with the smallest total payoff.
- `Fund Period CAGR %` switches between CAGR and simple return depending on the period length.
- `Cumulative FII Net (Cr)` is a running total over `ALLSELECTED` dates.
